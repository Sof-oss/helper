# Приём гайдов: Yandex Cloud Functions

Форма «Отправить свой гайд» (страница /guides) отправляет гайд сюда. Функция проверяет «я не робот»
(Cloudflare Turnstile) и создаёт в репозитории pull request с файлами `guides/<адрес>/index.md` и картинками.
На сайт гайд попадает только после **Merge**.

Почему не Cloudflare Worker (`worker/`): у части российских провайдеров соединения с Cloudflare обрываются,
и гайды с картинками не доходят. Серверы Яндекса в России, с ними такой проблемы нет.
Бесплатного объёма Cloud Functions (1 млн вызовов в месяц) хватает с запасом.

Нужны: Secret Key виджета Turnstile (Cloudflare → Turnstile → виджет) и токен GitHub — те же, что для Worker.

## 1. Создать функцию

1. https://console.yandex.cloud → каталог **default** → сервис **Cloud Functions**
   (в списке «Все сервисы» → раздел **Serverless**).
2. **Создать функцию** → имя `hotz-guides` → **Создать**.
3. Откроется выбор среды: **Node.js 22**. Галочку «Добавить файлы с примерами кода» снимите → **Продолжить**.

## 2. Код и параметры

1. **Способ**: Редактор кода → **Создать файл** → имя `index.js` → вставьте целиком содержимое `yandex/index.js`.
2. **Точка входа**: `index.handler`.
3. **Таймаут**: `30` секунд (по умолчанию 3 — мало: функция успевает сходить в GitHub несколько раз).
4. **Память**: 128 МБ. **Сервисный аккаунт**: не нужен.
5. **Переменные окружения** → добавьте пять штук:

   | Ключ | Значение |
   |---|---|
   | `GITHUB_TOKEN` | токен GitHub (`github_pat_…`) |
   | `TURNSTILE_SECRET` | Secret Key из Turnstile |
   | `GITHUB_REPO` | `Sof-oss/helper` |
   | `GITHUB_BRANCH` | `main` |
   | `ALLOWED_ORIGINS` | `https://heart-of-the-zone.ru` |

6. **Сохранить изменения** — создастся версия функции.

## 3. Открыть доступ

1. Вкладка **Обзор** → переключатель **Публичная функция** — включить (иначе браузер посетителя не сможет её вызвать).
2. Там же скопируйте **Ссылку для вызова**: `https://functions.yandexcloud.net/d4e…`
3. Откройте эту ссылку в браузере — должно показаться `{"ok":false,"error":"Нужен POST"}`.

## 4. Включить на сайте

В `guides-config.js` замените `endpoint` на ссылку из шага 3 и закоммитьте:

```js
endpoint: "https://functions.yandexcloud.net/d4e…",
```

`turnstileSiteKey` остаётся прежним.

## Потом

- Поменять токен или другую переменную: функция → **Редактор** → переменные окружения → **Сохранить изменения**.
- Логи: функция → **Логи** (видно ошибки GitHub, если токен истёк или у него не хватает прав).
- Лимиты отправки: до 5 картинок, каждая до 1 МБ после сжатия в браузере, вместе до 2,4 МБ
  (у Яндекса запрос целиком — до 3,5 МБ).
- Как проверять и публиковать гайды — `worker/README.md`, раздел «Как проверять и публиковать гайды».
