# Для разработчика

Технические заметки по сайту «Сердце Зоны». Игрокам это знать не нужно - описание сайта в [README.md](README.md).

Сайт статический, собирается в `dist/` и выкладывается на GitHub Pages (`.github/workflows/pages.yml`).

```sh
npm ci
npm run build        # build-guide-images.js + build.js + build-previews.js -> dist/ (в деплое перед ними ещё build-changelog.js)
npm test             # тесты (test/*.test.mjs): расчёт урона (src/calc-core.js), разметка гайдов (guide-md.js), изменения Топ-100 (build-top100.js)
npm run lint         # ESLint
npm run format       # Prettier
npm run format:check # Prettier: только проверить, ничего не меняя (так же, как в деплое)
```

## Как запустить локально

Проще всего - двойной клик по `dev.bat` (или `node dev.js`): сайт соберётся, откроется http://localhost:3000,
а после каждого сохранения файла пересоберётся сам и обновит открытые вкладки. Ошибка сборки видна в окне
`dev.bat` и плашкой на странице. Офлайн-кэш (service worker) там выключен, чтобы не мешал старой версией;
проверить офлайн-режим - `node dev.js --sw`. Другой порт - `--port 3001`. Картинки гайдов и превью `dev.js`
не пересобирает - для них `npm run build`.

Вручную:

```sh
npm ci
npm run build        # или только node build.js, если картинки гайдов и превью не менялись
npx serve dist       # сайт откроется на http://localhost:3000
```

`serve` отдаёт страницы без `.html` в адресе (`/calculator`, `/top100`), как GitHub Pages.
Для картинок (`build-guide-images.js`, `build-previews.js`, `build-logo.js`) нужен установленный Chrome или Edge,
путь можно указать в переменной `CHROME_PATH`. Без Chrome сайт всё равно соберётся, только без новых картинок.

- Деплой запускает тесты, линтер и проверку форматирования (`npm run format:check`) перед сборкой: если что-то
  упало, сайт не обновится. Перед коммитом - `npm run format`.
- Стили: в исходниках страница подключает несколько css (`styles.css`, `calculator.css`, `home.css` …), а `build.js`
  склеивает их в один `bundle-<хэш>.css` на страницу и выкидывает правила, классы и id которых не встречаются ни в
  разметке страницы, ни в её скриптах (postcss). Классы из кусков строки (`"x-" + имя`, `` `x-${имя}` ``) очистка
  узнаёт по префиксу; если класс собран иначе и пропал на сайте - напишите его имя целиком где-нибудь в скрипте. `intro.css` подключает только
  встроенный скрипт интро и только новичкам.
- Живой 3D-фон главной (`src/zone-bg.js`) работает на `src/zone-gl.js` - маленькой обёртке WebGL с тем же API,
  что у three.js (только нужные классы). Сам three.js остаётся в devDependencies для картинок `build-logo.js`.
- `build.js` проставляет `?v=<хэш>` всем css/js/картинкам и добавляет в каждую страницу Content-Security-Policy
  (`<meta http-equiv>`) с хэшами встроенных скриптов. Новый встроенный `<script>` разрешится сам при сборке;
  внешний скрипт или новый адрес для `fetch` нужно добавить в `cspFor()` в `build.js`.
- Шрифты лежат в `assets/fonts/`, лицензия OFL - `assets/fonts/OFL.txt`. Моноширинный - ZoneMono (JetBrains Mono)
  в `mono-*.woff2`. Логотип - `graffiti-logo.woff2`, в нём только буквы «Сердце Зоны»; полный шрифт для превью -
  `previews/fonts/graffiti-stalker.ttf`.
- Общие куски страниц - `partials/header.html` (меню) и `partials/footer.html` (подвал со строкой «Неофициальный
  фан-сайт»); стили калькулятора - `calculator.css`.
- Картинки гайдов: `build-guide-images.js` кладёт рядом с каждой большой картинкой копию `<файл>-800w.webp` (для
  телефонов, через srcset) и обложку `og.jpg` 1200×630 для соцсетей. Готовые файлы коммитятся вместе с гайдом.
- Превью разделов для мессенджеров (`assets/preview-*.jpg`) и иконки (`favicon.svg`, `favicon.ico`) рисует
  `build-logo.js`. Ссылка «Поделиться билдом» ведёт на `/build#…`: у этой страницы своё превью «Смотри мой билд»,
  а сама она открывает калькулятор с билдом.
- `404.html` перенаправляет старые адреса: `/p/<id>` -> карточка игрока в Топ-100, адреса со слешем на конце
  или с `.html` -> адрес без них.
- Обновления пакетов предлагает Dependabot (`.github/dependabot.yml`), мажорные версии ESLint обновляются вручную.
- **PWA**: `manifest.webmanifest`, иконки `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` (рисует `build-logo.js`),
  service worker `sw.js`. Ссылку на manifest и `sw-register.js` build.js сам добавляет в каждую страницу; в `dist/sw.js`
  он подставляет версию сборки и список «оболочки» (основные страницы, `offline.html`, всё, что они подключают с `?v=`, иконки наград и картинки боссов без видео).
  Новая сборка - новый `sw.js`, браузер обновляет кэш сам. Страницы и данные Топ-100 - сначала из сети, файлы с `?v=` - из кэша.
  Новая основная страница - добавить её в `SHELL_PAGES` в build.js.
- **Моё место и сравнение игроков**: `zone-players.js` (общие помощники и поиск игрока), `my-place.js` (Топ-100, карточка
  игрока, блок на главной), `compare.js` + `compare.html`. Отметка «это я» - `localStorage.zoneMyPlayer`.
- **Темы группировок** (10 шт.): список и шевроны - `THEMES` и `GLYPHS` в `ui.js`; цвета - блок «Палитра тем» в `styles.css`,
  там же фон `--bg-img` (три размера), размытая заглушка `--bg-lq` и картинка в списке тем `.ti-thumb`; ещё список ключей
  в `build.js` (preload фона) и в регулярках `build-factions.js` / `build-previews.js`. Фоны: `assets/bg-<ключ>.webp`
  1920×1072, `-1280` 1280×714, `-m` 800×948, `-thumb` 336×80. Цвет группировки на сайте - `top100/factions.json`.
- **Оформление главной** (экран ПДА, лента, таблички разделов) - `home.css`, подключён только на главной.
  Медали 1–3 мест - `assets/medal-1.svg` … `medal-3.svg` (Топ-100, карточка игрока, сравнение, «Моё место»).
  Сравнение игроков в меню не выносится: вход - кнопка «Сравнить игроков» у заголовка Топ-100 и «Сравнить» в карточке.
- **Мои билды**: `src/calc-slots.js` (входит в calculator.js), слоты - `localStorage.zoneBuildSlots`, билд в слоте хранится
  той же строкой, что в «Ссылке на билд».
- **Топ-100 обновляется сам** (`.github/workflows/top100.yml`): каждый день в 06:17 МСК выгрузка из API игры
  (`fetch-players.js`) -> `build-top100.js` -> коммит данных -> деплой. Нужен секрет репозитория `ZONE_TOKEN`
  (Settings → Secrets and variables → Actions) - долгоживущий токен API от разработчика игры. Если токен истёк,
  запуск падает с ошибкой «Сервер не принял токен», GitHub присылает письмо, сайт остаётся с прошлыми данными.
  Вручную: вкладка Actions → «Обновление Топ-100» → Run workflow, или локально `update-top100.bat`
  (перед ним `git pull`, чтобы не разойтись с коммитами бота).
- Капча формы гайдов - Yandex SmartCaptcha или Cloudflare Turnstile (`guides-config.js`, см. `yandex/README.md`).
