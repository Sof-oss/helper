# Скиллы проекта

Перед любой задачей по сайту прочитай файл AGENTS.md в корне репозитория. В нём список скиллов проекта и главные правила.

Выбери по таблице из AGENTS.md подходящий скилл, прочитай его файл .claude/skills/<имя>/SKILL.md целиком и работай по нему. В конце задачи используй скилл verify-and-ship (.claude/skills/verify-and-ship/SKILL.md).
