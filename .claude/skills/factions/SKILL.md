# Группировки и темы группировок

## Когда использовать

- Девиз, набор, условие приёма, группа ВК, контакты, скрытие группировки - `factions-info.json`.
- Вопросы «откуда цифры» на /factions и в штабе (бойцы, места, рейтинг, история).
- Цвет группировки, новая группировка в игре, новая тема оформления (фон, палитра, эмблема).
- Не сюда: выгрузка, Топ-100, карточки игроков (`player-card.js`) - скилл **top100**; Хэллоуин и праздники -
  **seasonal-events**; сборка, CSS-очистка, CSP, превью - **site-dev**; запись в «Новости сайта» - **site-news**;
  проверка и PR - **verify-and-ship**.

## Файлы

- `factions-info.json` - ручные данные группировок (единственное, что правится руками в обычных задачах).
- `build-factions.js` - при сборке рисует сводку, рейтинг активности и карточки /factions, а также данные штабов
  (`cards`, `build.js` пишет их в `dist/factions-cards.json`). Экспорт для тестов: `esc`, `safeUrl`, `anchor`, `slugOf`, `slotCap`.
- `factions.html` - каркас страницы (`#factionsStats`, `#factionsRank`, `#factionsList` заполняет `build.js` → `PRERENDER["factions.html"]`).
- `factions.js` - поиск (по названию и по нику бойца из `data-players`), фильтры «Набор открыт» / «Есть места»,
  сортировка, рейтинг за период. `factions.css` - стили страницы.
- `faction-card.js` + `faction-card.css` - окно «Штаб» (подключено на /factions и в Топ-100), открывается по
  `data-fc-open="<slug>"`, `data-fc-name="<имя>"` (из карточки игрока) или `#f=<slug>`.
- `build.js` → `writeFactionCards()` - `dist/factions-cards.json` и страницы `dist/f/<slug>.html` (превью для мессенджеров,
  `location.replace("/factions#f=<slug>")`).
- Автоматические данные (руками НЕ править): `top100/clans.json` (список из API игры `/clans/search`: name, level,
  members, leader{id,name}; перезаписывает `fetch-players.js` каждую ночь), `top100/clans-history.json`
  (`fetch-players.js` → `recordClansHistory()`: строки `[дата, уровень, бойцов, id лидера]` только при изменениях),
  `top100-players.json` (`g` - группировка, `gh` - история группировок `[индекс даты, имя]`, `v`/`s` - показатели).
- `top100/factions.json` - цвет группировки `{"Имя": "#rrggbb"}`; новым группировкам цвет дописывает `build-top100.js`
  (`pickColor`), руками можно поправить.
- Темы: `ui.js` (`THEMES`, `GLYPHS`), `styles.css`, `zone3d.css`, `build.js`, `build-factions.js`, `build-previews.js`,
  `build-depth.py`, `assets/bg-<ключ>*.webp`, `assets/depth-<ключ>*.webp`, `assets/emblem-<ключ>.webp` - чек-лист ниже.

## Формат factions-info.json

Объект: ключ - название группировки **символ в символ как в игре** (как `name` в `top100/clans.json`, с регистром и
пробелами: `"Winx club"`, `"L E G I O N"`). Ключ с несуществующим именем молча игнорируется. Ключ `_about` - строка-описание,
не трогать. Все поля необязательные, других полей код не читает (`build-factions.js` → `cardsData`):

| Поле | Тип | Где видно |
|---|---|---|
| `motto` | строка, без кавычек (кавычки «» ставит код) | карточка на /factions, штаб, описание превью /f/<slug> |
| `recruit` | строка | непустая = набор открыт: плашка «Набор открыт», фильтр, счётчик «ведут набор», «набор у N» на главной, текст в штабе; на карточке /factions - только если нет `motto` |
| `requirement` | строка, читается после слова «приём» («с 10 уровня») | штаб, строка «Набор: Открыт приём …»; без `recruit` не показывается |
| `vk` | `{ "url": "https://…", "name": "…" }` | кнопка «Группа ВКонтакте»; `name` по умолчанию «Группа ВКонтакте» |
| `contacts` | `[{ "name": "…", "url": "https://…" }]` | «Связь» в штабе; без `url` - просто имя; `@` в начале имени срезается; ссылки vk.ru/vk.com/m.vk.* получают иконку ВК |
| `post` | `"https://…"` | кнопка «Пост о наборе» в штабе; откуда взяты данные |
| `hidden` | `true` | группировка полностью убирается со страницы, из рейтинга и штабов (служебные) |

Все ссылки проходят `safeUrl`: только `https://` без пробелов и `"<>`. `http://`, `//…`, `javascript:` молча выкидываются
(у `vk` пропадает вся кнопка). Лидер, уровень, состав, места, история - из выгрузки, в этот файл их не писать.

```json
"Свобода": {
  "motto": "Вместе мы сделаем Зону свободной!",
  "recruit": "Вливайся в ряды «Свободы», сообща мы сохраним Зону!",
  "requirement": "с 10 уровня",
  "vk": { "url": "https://vk.ru/club241112117", "name": "«Свобода» Сердце зоны" },
  "contacts": [{ "name": "Danya Krapivin", "url": "https://vk.ru/moralis_m" }],
  "post": "https://vk.ru/topic-239092289_68513320?post=132"
}
```

Обсуждение «Группировки» сообщества игры: `https://vk.ru/topic-239092289_68513320` (ссылка на пост - `?post=<номер>`).
Файл форматирует Prettier (2 пробела, массивы объектов раскрыты) - после правки `npm run format`.

## Откуда цифры (для ответов «почему не так»)

- **Список группировок**: все из `top100/clans.json` + те, что встречаются только у игроков выгрузки; минус `hidden`.
- **Бойцов** = max(`members` из API, бойцов в выгрузке). Состав в штабе - только игроки с прогрессом из ежедневной
  выгрузки (остальные - «Ещё N бойцов пока без прогресса»). Лидер - `leader` из API (ссылка на карточку, если он есть в выгрузке).
- **Места** (`slotCap`): 20 сначала; на 2 / 5 / 10 уровне можно взять расширение до 25 / 30 / 40 (а можно другое
  улучшение). Берётся наименьший лимит, доступный по уровню и вмещающий максимум бойцов за историю; если подходит
  больше одного - лимит неизвестен (`cap: null`, показывается просто число бойцов, «Есть места» не срабатывает).
- **Рейтинг активности**: по 7 показателям (репутация, боссы, тайники, таланты, коллекции, вылазки, защита лагеря) сумма
  по бойцам выгрузки; каждая сумма делится на лучшую среди группировок; активность = среднее × 100. Порядок карточек на
  странице - по активности (при равенстве - бойцы, затем имя). «Всё время» - текущие суммы; период (сутки/неделя/месяц/свой) -
  прирост, сделанный бойцом, пока он числился в группировке (по `gh`; первый снимок бойца - точка отсчёта, учитывается
  только рост). Пересчёт за период делает `factions.js` из `<script id="fxRankHistory">`.
- **История штаба** (до 300 событий, видно 12): вступления/уходы - из `gh` игроков; уход и вступление в другую группировку
  в пределах 7 дней склеиваются в «ушёл в «X»» / «из «A»». Уровень, «Места расширены» и «Новый лидер» - из строк
  `clans-history.json`. История копится только с начала записи (первая строка - 2026-10-26), раньше событий нет.
- **Slug** (`slugOf`): `anchor(name)` без `f-` - нижний регистр, всё кроме a-z0-9а-яё → «-», кириллица транслитом
  (`TRANSLIT`: «Наёмники» → `naemniki`, «Last Way 2» → `last-way-2`); если букв не осталось - хэш `g<base36>`.
  Переименовали группировку в игре - сменится и адрес `/f/<slug>`: старая страница `/f/<старый>` больше не собирается (404),
  а `/factions#f=<старый>` просто откроет список.

## Сценарии

### Обновить набор / девиз / контакты по посту в обсуждении ВК
1. Открой пост (WebFetch по ссылке `…topic-239092289_68513320?post=N`). Если ВК не отдаёт текст - попроси у пользователя
   текст поста, не выдумывай.
2. Найди ключ: точное имя из `top100/clans.json` (`jq -r '.clans[].name' top100/clans.json`).
3. Перенеси в поля: девиз → `motto` (без внешних кавычек), призыв → `recruit`, условие → `requirement`, группа →
   `vk`, люди → `contacts`, ссылку на пост → `post`. Смысл и формулировки автора сохраняй; правь только оформление:
   кавычки «ёлочки», дефис «-» вместо тире, без лишних эмодзи/капса. Ссылки приводи к `https://` (vk.com и vk.ru оба годятся).
4. Набор закрыли - удали `recruit` (и `requirement`), а не пиши «набор закрыт».
5. Проверка (ниже), коммит через verify-and-ship. Для заметной правки - запись в «Новости сайта» (скилл site-news).

### Скрыть служебную группировку
`"Имя как в игре": { "hidden": true }` (пример - `"О-Сознание"`). Бойцы остаются в Топ-100 и карточках игроков, исчезает
только сама группировка на /factions, в рейтинге и штабах; её страница `/f/<slug>` больше не собирается.

### В игре появилась новая группировка
Появляется на /factions сама после ночной выгрузки (`clans.json`), руками ничего добавлять не нужно. Без темы она
получает щиток с первой буквой в своём цвете (`shield()`), карточку без фото (`fx-photo-tint`) и штаб без фона (`fc-nobg`).
- Цвет: `build-top100.js` сам допишет цвет в `top100/factions.json`, когда её бойцы попадут в Топ-100; до этого - серый
  `#8fa3b4`. Задать/поменять руками - hex `#rrggbb` в `top100/factions.json` (ключ - точное имя), не совпадающий с
  соседями. /factions подхватит при сборке; Топ-100 и карточки игроков (`TOP100_FACTIONS`, `factions` в `top100-players.json`) -
  после следующего прогона `build-top100.js`/`build-players.js` (ночное обновление).
- Девиз/набор - сценарий выше. Своя эмблема и фон бывают только у тем: делай тему лишь по просьбе владельца (Sof).

### Добавить новую тему оформления (чек-лист)
Тема привязана к группировке по `label` = имя в игре (`KEY`/`__factionEmblem` ищут по label): тогда эмблема темы идёт в
карточки /factions, рейтинг, штаб, Топ-100, карточки игроков и превью, а фото - фоном карточки и штаба. Ключ - латиница
`[a-z]+` (тест `zone-bg` и регулярки рассчитаны на это). Образец полного набора - тема `bandits` (коммит `2ae7cf3`).
1. `ui.js` → `THEMES`: `{ key, label, color, color2, tint }` (`color`/`color2` - значок и пункт в списке тем, `tint` - тёмный
   цвет для `<meta name="theme-color">`). Порядок массива = порядок в списке тем.
2. `ui.js` → `GLYPHS`: `key: '<svg-элементы в viewBox 0 0 64 72>'` - одна строка в **одинарных** кавычках (внутри только
   двойные), иначе её не прочитают регулярки сборки. Растровая эмблема: `'<image href="/assets/emblem-<key>.webp" x="0" y="0" width="64" height="72" preserveAspectRatio="xMidYMid slice"/>'`
   + файл `assets/emblem-<key>.webp` (у bandits 160×180).
3. Регулярки с перечнем ключей - дописать `|<key>`: `build-factions.js` (`GLYPHS = …matchAll(/^\s*(merc|…|bandits):/`) и
   `build-previews.js` (то же). Счётчики-предохранители `< 11` поднять до нового числа тем в `build-factions.js`,
   `build-previews.js` и `build.js` → `factionEmblem()`.
4. `build.js` → массив `THEMES` в блоке «preload фона темы» (ключи для preload фона).
5. `build-depth.py` → список `THEMES`.
6. `styles.css`:
   - фон `--bg-img`: блок `:root[data-theme="<key>"]` в начале файла (`bg-<key>.webp`), в `@media (max-width: 1366px)`
     (`-1280`) и в `@media (max-width: 760px)` (`-m`);
   - палитра: блок `:root[data-theme="<key>"]` рядом с остальными (после `clearsky`, перед `body::after`) с полным набором
     `--accent`, `--accent-2`, `--accent-3`, `--accent-ink`, `--glass-line`, `--wash`, `--panel`, `--panel-2`,
     `--panel-line`, `--bg-dim` (затемнение фото, 0.34-0.58);
   - заглушка `--bg-lq`: у старых тем - крошечный размытый webp 32×18 в base64 после блока `@media 760px`; у `bandits` -
     `--bg-lq: linear-gradient(…)` прямо в палитре. Как делались base64-заглушки - уточнить у владельца; градиент - допустимый вариант;
   - `.theme-item[data-theme-btn="<key>"] .ti-thumb { background-image: url("assets/bg-<key>-thumb.webp"); }`.
7. `zone3d.css`: `--depth-img` для `:root[data-theme="<key>"]` (`depth-<key>.webp`) и в `@media (max-width: 760px)` (`depth-<key>-m.webp`).
8. Картинки (webp, кадр одного фото): `assets/bg-<key>.webp` 1920×1072, `bg-<key>-1280.webp` 1280×714, `bg-<key>-m.webp`
   800×948 (вертикальный кадр для телефона), `bg-<key>-thumb.webp` 336×80 (список тем), `bg-<key>-card.webp` 720×260
   (карточка на /factions). Ориентир веса: 100-260 / 50-140 / 35-95 / 3-5 / 12-26 КБ.
9. Карты глубины: `pip install onnxruntime pillow numpy`, `python3 build-depth.py <key>` → `assets/depth-<key>.webp`
   960×536 и `depth-<key>-m.webp` 480×569. Без них фон работает, но тест `zone-bg` упадёт на ссылку без файла. Перегенерировать и при замене фото темы.
10. Цвет в `top100/factions.json` для этой группировки привести к `color` темы (у существующих совпадает).
11. Документация: число и список тем в `README.md` («Удобство») и `DEVELOPMENT.md` («Темы группировок»); новость - скилл site-news.

## Подводные камни

- `factions-info.json` ломается одной запятой: `build-factions.js` бросит `factions-info.json: …` и сборка/деплой упадут.
- Имя-ключ с опечаткой, «ё» вместо «е» или лишним пробелом - данные просто не покажутся, ошибки не будет. Сверяй с `clans.json`.
- Не вписывай HTML: всё экранируется (`esc`) и покажется текстом. Переносы строк в тексте не сохраняются.
- `requirement` без `recruit` не виден; `recruit` на карточке /factions скрыт, если есть `motto` (виден в штабе).
- Тема по умолчанию и запасная - `merc` (`ui.js`, `:root` в `styles.css`/`zone3d.css`, `M.merc` в preload `build.js`,
  `src/zone-theme.js`). Ключ темы хранится в `localStorage.zoneTheme`, значок шапки - `zoneThemeBadge`; неизвестный ключ → `merc`.
- Новые CSS-классы, собранные из кусков строк, может выкинуть очистка CSS в `build.js` - см. site-dev.
- В README/DEVELOPMENT сейчас написано «10 тем», а в коде 11 (есть «Бандиты») - при правке тем исправь заодно.

## Проверка

1. `npm test` - `test/build-factions.test.mjs` (экранирование, `safeUrl`, `anchor`/`slugOf`, `slotCap`, история и события
   штаба) и `test/zone-bg.test.mjs` (файлы карт глубины). Тесты пишут только во временные папки.
2. JSON: `node -e "JSON.parse(require('fs').readFileSync('factions-info.json','utf8'))"`; `npm run format:check`.
3. Сборка и просмотр - по verify-and-ship (`node build.js`, `npx serve dist` или `node dev.js`). Быстро проверить данные:
   `jq '.factions[] | select(.n=="Свобода") | {s,motto,recruit,req,vk,contacts,post,cap,rank}' dist/factions-cards.json`.
4. Глазами:
   - `/factions` - сводка, топ-5 и «Весь рейтинг», карточка группировки (девиз/набор, «Набор открыт», бойцы `N/лимит`),
     поиск по нику бойца, фильтры и сортировка;
   - штаб: клик по карточке или `/factions#f=<slug>` (в `serve` также `/f/<slug>` → переадресация) - лидер, «Набор», «Связь»,
     кнопки группы ВК и «Пост о наборе», состав, история; ссылка «копировать» даёт `/f/<slug>`;
   - тема: кнопка «Группировка» в шапке → выбрать тему; проверить фон на ширине >1366, ~1280 и ≤760 px, превью в списке,
     цвета панелей, живой фон главной, эмблему в карточках /factions, Топ-100 и карточке игрока; после перезагрузки тема сохраняется.
