# Сезонное оформление

## 1. Когда использовать

- Оформление поверх всего сайта на время праздника: `season.js` + `halloween.js` + `halloween.css` + `assets/halloween/`.
- НЕ сюда:
  - баннер события в карточке «Новостей Зоны» (поле `event` в `news.js`: `"halloween"`, `"update-halloween"`, `"halloween-end"`, картинки `assets/event-*.webp`) - скилл **zone-news**;
  - ивентовые боссы и их метка «Хэллоуин · временный» (`info-bosses.js`) - скилл **game-info**;
  - общая сборка, CSP, PWA, шапка вообще - **site-dev**; проверка и публикация - **verify-and-ship**.

## 2. Файлы

| Файл | За что отвечает |
|---|---|
| `season.js` | Загрузчик на КАЖДОЙ странице. Окно дат `var SEASON = {...}`, уровни `LEVELS`, ключ `localStorage` `KEY = "hotzHalloween"`, меню кнопки-тыквы, ленивая загрузка `halloween.css`/`halloween.js`, `window.HOTZ_HW_V` (версия из `__HW_V__`). |
| `halloween.js` | Сама нечисть: вороны, тыквы, пасхалка-тыква, бюрер, призраки, зомби-монолитовец, туман, фонарик. Наружу - `window.HOTZ_HW = { start, stop }`. |
| `halloween.css` | Стили декора (`.hw-layer`, `.hw-sky`, `.hw-fog`, `.hw-crow`, `.hw-pumpkin`, `.hw-egg` …), мобильная версия `@media (max-width: 720px)`, `@media (prefers-reduced-motion: reduce)`, подсветка `html.hw .zn-event`. |
| `assets/halloween/*.webp` | Спрайты: `crow-sit/-fly-up/-fly-down`, `pumpkin-artifact/-dosimeter/-gasmask/-helmet`, `ghost-alpha/-boar/-ghoul/-izlom/-rat/-swamp`, `burer-peek`, `burer-sheet`, `monolith-stand`. |
| `partials/header.html` | Кнопка `#hwToggle` в `.hw-switch` внутри `.header-tools` (SVG тыквы, `aria-label`) и однострочный встроенный скрипт шапки (`<!-- prettier-ignore -->`) с плейсхолдером `__HW_SEASON__`. |
| `styles.css` | Кнопка и меню: `.hw-switch` (по умолчанию `display: none`, `html.hw-season .hw-switch { display: block }`), `.hw-switch + .theme-pick`, `.hw-toggle`, `.hw-menu`, `.hw-mi`, `@keyframes hw-candle`. |
| `my-place.js` + `my-place.css` | Звание «Тыквенный сталкер» (`.hw-rank`) в своей карточке игрока: `HW_FOUND_KEY = "hotzHwFound"`, `HW_EGG_PAGES = 6`. |
| `build.js` | `HW_SEASON` (вырезает `{...}` из `season.js` регуляркой `/var SEASON = (\{[^}]*\});/` и подставляет в шапку в `applyIncludes`), `LAZY_JS["season.js"] = ["halloween.js"]`, `EVERY_PAGE_JS`, `pwaTags()` (добавляет `<script src="/season.js" defer>` на все страницы), блок с `hwDir` (хэш `halloween.css` + `halloween.js` + всех файлов `assets/halloween/` -> вместо `__HW_V__` в `dist/season.js`). |

Тестов на сезон в `test/` нет.

## 3. Как это работает (проверено по коду)

**Окно сезона** - `var SEASON = { mode: "auto", from: "10-20", to: "11-03" };` в `season.js`:
- `mode`: `"auto"` - по датам; `"on"` - всегда; любое другое (принято `"off"`) - выключено: кнопки нет, декор не грузится.
- `from`/`to` - строки `"ММ-ДД"` с ведущим нулём, сравниваются как строки, обе границы включительно. `from > to` = окно через Новый год (`"12-20"`…`"01-10"` работает).
- Дата - по часам и часовому поясу посетителя (`new Date()` в браузере), не МСК. Год не учитывается: в `auto` окно само повторяется каждый год, пересборка не нужна.
- Одна и та же проверка дублируется во встроенном скрипте шапки (до отрисовки ставит `hw-season` на `<html>`, `aria-pressed` и `title` кнопки) и в `season.js`. Объект `SEASON` в шапку подставляет `build.js` - править нужно только `season.js`.

**Уровни** (`LEVELS` в `season.js`, хранятся в `localStorage.hotzHalloween`): `off` «Выкл», `quiet` «Тихо» (по умолчанию: тыквы, вороны, пасхалка), `season` «Сезон» (+ бюрер, призраки, монолитовец, сбой заголовков, прыжки ворон), `surge` «Выброс» (всё чаще в 1/0.55 раза, 7 ворон, темнее туман, фонарик за курсором). Старое значение `"on"` читается как `season`, мусор - как `quiet`. То есть в сезон декор включён у всех, посетитель отключает его кнопкой-тыквой -> «Выкл».
- Классы на `<html>`: `hw-season` - сезон идёт (показывает кнопку), `hw` - декор включён, `data-hw="<уровень>"`.

**Лениво и без вреда для скорости и офлайна:**
- `season.js` маленький, `defer`; вне сезона сразу `return`.
- `halloween.css`/`.js` вставляются только при уровне не `off` (`load()`), с `?v=<HOTZ_HW_V>`; картинки - через `img()` в `halloween.js` тоже с этим `?v=`. Тыквы появляются через 900 мс, все слои `aria-hidden`.
- Если идёт интро ПДА (`html.intro`), `halloween.js` ждёт событие `zone-intro-done`.
- Выбор «Выкл» вызывает `HOTZ_HW.stop()`: снимает таймеры, слушатели, `ResizeObserver`, удаляет все узлы.
- Service worker: `halloween.*` и спрайты не входят в статическую оболочку (их нет в HTML), но идут с `?v=` -> `cacheFirst` в `zone-runtime`. Офлайн декор есть, только если его уже грузили онлайн; иначе тихо не появится. `season.js` в оболочке есть.
- CSP: всё с `'self'`, встроенный скрипт шапки получает хэш автоматически (`cspFor`). Внешние адреса декору не нужны.
- Очистка CSS (`purgeCss`) `halloween.css` не трогает (он не подключён в HTML и не склеивается), а классы `.hw-*` в `styles.css` выживают, потому что встречаются в `season.js`/`halloween.js` (через `EVERY_PAGE_JS` и `LAZY_JS`).

**Мобильная версия** (`narrow = max-width: 720px`): 3 вороны вместо 5/7, 2 тыквы вместо 4, нет бюрера и монолитовца, призраки в масштабе 0.6; фонарик - только при `(hover: hover) and (pointer: fine)`. Учти: декор ломается на 720 px, а сайт - на 760 px.

**prefers-reduced-motion учитывается:** `full()` ложно -> на любом уровне только тихий набор (вороны, тыквы, пасхалка), без бюрера, призраков, монолитовца, сбоя заголовков, фонарика; вороны не вспархивают; CSS-анимации выключены (в т.ч. свечка на кнопке).

**Пасхалка «Тыквенный сталкер»:** одна тыква-кнопка на разделах `EGG_PAGES = ["/", "/info", "/top100", "/compare", "/calculator", "/guides"]` (`/info-*` -> `/info`, `/guide/*` -> `/guides`, `/build` -> `/calculator`), найденные - в `localStorage.hotzHwFound`. Собрал все 6 и отметил себя «Это я» - в своей карточке игрока звание (`my-place.js`), показывается и вне сезона.

## 4. Сценарии

### Выключить сейчас / включить на проверку
1. В `season.js` поменяй только `mode` в `var SEASON = {...}`: `"off"` или `"on"`. Строку держи в одну строку и без вложенных `{}`, иначе `build.js` упадёт с «не найдена строка var SEASON».
2. Коммить `"on"` только если владелец просит включить сейчас - в истории уже был ошибочный коммит `mode: "on"` и откат на `"auto"`.

### Хэллоуин в следующем году
- Ничего делать не нужно: `mode: "auto"` сработает 20.10-03.11 сам. Сдвинуть - поменяй `from`/`to` (формат `"ММ-ДД"`).
- Если дата игрового события известна - уточни у владельца, совпадать ли с ним; баннеры в «Новостях» ведёт **zone-news**.

### Правка декора
- Новый спрайт: `.webp` в `assets/halloween/`, имя без расширения - в `halloween.js` через `img("имя")` (не пиши путь вручную - потеряется `?v=`). Версия пересчитается сама: хэш берёт все файлы папки.
- Новый уровень или подпись уровня: меняй `LEVELS` в `season.js` И словарь подписей во встроенном скрипте шапки (`{off:"выкл",season:"сезон",on:"сезон",surge:"выброс"}`, по умолчанию «тихо») - иначе `title` кнопки разойдётся.
- Новый раздел для пасхалки: `EGG_PAGES` + `EGG_NAMES` в `halloween.js` И `HW_EGG_PAGES` в `my-place.js` (сейчас 6, считается отдельно).
- Новые места посадки - селекторы `PERCH` / `PUMPKIN_PERCH` / `EGG_SPOTS`; на кликабельное (`CLICKABLE`) декор не садится - не ломай это.

### Новый сезон (например, Новый год) по образцу Хэллоуина
Сначала реши с владельцем: отдельная кнопка (по образцу, проще и не трогает Хэллоуин) или одна общая кнопка для всех праздников (рефакторинг `season.js`, шапки и `build.js`). По умолчанию - отдельная, префикс `ny`. Окна не должны пересекаться, иначе в шапке две кнопки. Чек-лист:
1. `newyear.js` (декор, `window.HOTZ_NY = { start, stop }`, `img()` с `window.HOTZ_NY_V`, учти `prefers-reduced-motion`, `max-width: 720px`, ожидание `zone-intro-done`) и `newyear.css` (свои классы `ny-*`, корень `html.ny`, блоки для узкого экрана и reduced-motion).
2. `assets/newyear/*.webp` - спрайты небольшие (у Хэллоуина 6-24 КБ).
3. Загрузчик: копия `season.js` (например `season-ny.js`) со своими `var SEASON_NY = { mode, from: "12-20", to: "01-10" }`, `KEY` (например `"hotzNewYear"`), `__NY_V__`, классами `ny-season`/`ny`/`data-ny`, `#nyToggle`, `.ny-switch`, `.ny-menu`, `[data-ny-level]`.
4. `build.js`:
   - аналог `HW_SEASON` для своей строки + `split("__NY_SEASON__").join(...)` в `applyIncludes`;
   - `LAZY_JS["season-ny.js"] = ["newyear.js"]` и `"season-ny.js"` в `EVERY_PAGE_JS` - иначе очистка CSS выкинет стили кнопки из `styles.css`;
   - в `pwaTags()` вставка `<script src="/season-ny.js" defer>` по образцу `season.js`;
   - копия блока с `hwDir`: хэш `newyear.css` + `newyear.js` + `assets/newyear/` -> замена `__NY_V__` в `dist/season-ny.js`.
5. `partials/header.html`: `<div class="ny-switch"><button id="nyToggle" class="ny-toggle" …>` в `.header-tools` перед `#themeSwitch`; во встроенный скрипт шапки - проверка `__NY_SEASON__` и `classList.add("ny-season")`, `aria-pressed`/`title` по своему ключу. Скрипт остаётся одной строкой; CSP-хэш пересчитается сам.
6. `styles.css`: `.ny-switch { display: none }`, `html.ny-season .ny-switch { display: block }`, отступ к `.theme-pick` (как `.hw-switch + .theme-pick`), кнопка и меню для мобильной шапки.
7. CSP и `sw.js` не трогай - всё с `'self'` и `?v=`. Нужен внешний ресурс - тогда `cspFor()` (**site-dev**).
8. Документация: строка про сезонные украшения в `README.md`, абзац про кнопки шапки в `DEVELOPMENT.md`. Запись для игроков - в `site-news.json` (**site-news**).

### Убрать сезон полностью
Обычно хватает `mode: "off"`. Если удалять код:
- Удали `halloween.js`, `halloween.css`; `season.js` удаляй только вместе с блоком `HW_SEASON` в `build.js` - он читает файл без проверки и упадёт.
- `assets/halloween/` целиком не удаляй: `assets/halloween/pumpkin-artifact.webp` использует `info-bosses.js` (метка ивентового босса).
- В `build.js` убери `HW_SEASON`, `__HW_SEASON__` в `applyIncludes`, `LAZY_JS["season.js"]`, `"season.js"` в `EVERY_PAGE_JS`, вставку в `pwaTags()`, блок `hwDir`.
- В `partials/header.html` - `.hw-switch` и hw-часть встроенного скрипта; в `styles.css` - правила `.hw-*`. Звание `.hw-rank` в `my-place.*` - спроси владельца, оставить ли.

## 5. Подводные камни

- `var SEASON = {...}` - одна строка, без вложенных фигурных скобок и без комментариев внутри.
- Встроенный скрипт шапки помечен `<!-- prettier-ignore -->` - не переформатируй его и не разбивай на строки.
- Кнопка-тыква уже есть в разметке на всех страницах; `season.js` её только оживляет (создаёт, лишь если в шапке её нет). Видимость решает класс `hw-season` до отрисовки - так шапка не прыгает.
- Пути к картинкам декора в JS собираются из кусков, поэтому `build.js` не ставит им `?v=` - только через `img()` и `HOTZ_HW_V`.
- Классы, которые декор вешает на чужие блоки: `hw-tk` (телекинез), `hw-flick` (сбой заголовка) - `stop()` их снимает; `hw-egg-host` (у `.result-panel` калькулятора) - не снимает.
- Тексты - по-русски, кавычки «ёлочки», только дефис «-». Комментарии в коде - короткие, по-русски, как в файле.
- `dist/` не коммитится; деплой - пуш в `main` (GitHub Pages), сборка там же.

## 6. Проверка

Общие шаги (тесты, линт, формат, сборка, скриншоты) - **verify-and-ship**. Специфика:
- Синтаксис после правок: `node --check season.js && node --check halloween.js` (по одному файлу за вызов); `node build.js` не должен упасть на `HW_SEASON`.
- Посмотреть глазами: `node dev.js` -> http://localhost:3000 (SW там выключен; офлайн - `node dev.js --sw`). В собранном `dist/season.js` не должно остаться `__HW_V__`, в `dist/*.html` - `__HW_SEASON__`.
- Вне сезона код поддерживает только два способа увидеть декор (параметра в адресе и ключа `localStorage` для даты НЕТ):
  1. временно `mode: "on"` в `season.js` (не коммитить);
  2. подменить часы браузера, например Playwright (`playwright-core` есть в devDependencies): `await page.clock.setFixedTime(new Date("2026-10-25T12:00:00"))` до `page.goto` - сработает и шапка, и `season.js`.
- Уровень выбирай кнопкой или заранее: `localStorage.setItem("hotzHalloween", "surge")` (`off`/`quiet`/`season`/`surge`).
- Пройди: главная, `/calculator` (монолитовец-мишень в `.result-panel`), `/top100` или `/compare` (идущий монолитовец), `/info`, `/guides`. Меню тыквы открывается, `Escape` закрывает, «Выкл» убирает весь декор без перезагрузки, выбор помнится после перезагрузки.
- Узкий экран 390×844: кнопка в шапке не наезжает на тему и «?», меню не уходит за край, декор не закрывает текст и кнопки.
- `prefers-reduced-motion`: в DevTools (Rendering -> Emulate CSS media) или `page.emulateMedia({ reducedMotion: "reduce" })` - на уровне «Выброс» остаются только тихие украшения без анимаций.

## 7. Связанные скиллы

- **zone-news** - баннеры событий в «Новостях Зоны» (`event` в `news.js`); `halloween.css` в сезон лишь подсвечивает `.zn-event`.
- **game-info** - ивентовые боссы (`info-bosses.js`).
- **top100** - карточка игрока, где показывается звание «Тыквенный сталкер».
- **site-dev** - `build.js`, CSP, service worker, шапка и стили в целом.
- **site-news** - запись о новом оформлении в «Новостях сайта».
- **verify-and-ship** - проверка, коммит, PR.
