# Новости Зоны (новости игры на главной)

## Когда использовать

- Новость игры: обновление, слухи, ивент, рейд, розыгрыш, промокод - по посту ВК или по тексту/скриншотам от пользователя.
- Правка старой записи (событие прошло, поправить текст, добавить скриншот), новый тип баннера события.
- НЕ сюда: «Новости сайта» (site-news.json, changelog.js) - скилл site-news; сезонное оформление сайта - seasonal-events; данные боссов/наград в «Информации» - game-info (часто их надо обновить вместе с новостью о новом боссе).

## Файлы

- `news.js` - всё в одном файле: данные `window.ZONE_NEWS` (вверху) и отрисовка (IIFE ниже): константы `FULL`, `SHOW`, `FRESH_DAYS`, `EVENT_HOURS`, таблица баннеров `EVENTS`, функции `eventState`, `promo`, `shots`, `banner`, `item`. `home-live.js` к новостям отношения не имеет (живые строки плашек).
- `index.html` - контейнер `<section id="zoneNews">`, подключает `lightbox.js` и `news.js`.
- `home.css` - стили `.zn-*`: список, компактные строки, `.zn-note`, `.zn-points`, `.zn-shots`, `.zn-promo`, баннеры `.zn-event`, `.zn-ev-<тип>`, `.zn-ev-ended`, `.zn-ev-dot`.
- `lightbox.js` + `lightbox.css` - окно просмотра (`window.ZoneLightbox.open(items, k)`, `big(img)` берёт самый крупный вариант из srcset); общий с гайдами.
- `assets/event-<тип>-600.webp` / `-1200.webp` - картинки баннеров событий; `assets/news/<ГГГГ-ММ-ДД>-<имя>.webp` + `-480.webp` - скриншоты новостей.
- `build.js` - `PRERENDER["index.html"]` прогоняет `news.js` в заглушке DOM (`runScripts`) и вшивает готовую разметку в `#zoneNews`; в браузере `news.js` перерисовывает блок заново. Ещё `build.js` дописывает `?v=<хэш>` к строкам `"/assets/....webp"` внутри js и меняет длинное тире на дефис в `dist/`. Sitemap, превью и тесты новости игры не трогают.

## Формат записи `window.ZONE_NEWS`

Массив объектов. **Порядок = порядок на странице, сортировки нет**: новую запись вставляй В НАЧАЛО массива. Записи без `title` отбрасываются. Все строки экранируются (`esc`) - HTML в полях не работает, пиши простой текст.

| Поле | Обяз. | Как рисуется |
|---|---|---|
| `date` | да | `"ГГГГ-ММ-ДД"` - дата поста/новости (не события). Показывается «8 ноя»; если моложе 3 дней (`FRESH_DAYS`) - значок NEW. Другой формат выведется как есть. |
| `title` | да | Заголовок `.zn-title`; в свёрнутых строках обрезается многоточием. |
| `text` | нет | Абзац под заголовком - главная мысль одной фразой. |
| `note` | нет | `{ title, text }` - второй абзац: `<b>title:</b> text`. `title` без двоеточия (оно добавится), `text` обязателен и начинается со строчной, т.к. продолжает фразу. |
| `points` | нет | Массив строк -> список с жёлтыми маркерами. |
| `shots` | нет | `[{ src, thumb, alt }]`: `src` обязателен (крупная), `thumb` - превью (иначе берётся `src`), `alt` - подпись в окне просмотра и aria-label. Пути с ведущим `/assets/news/...`. |
| `url` | нет | Ссылка «Читать в ВК» (`https://vk.ru/wall-239092289_NNN`); в компактной строке - стрелка. |
| `promo` + `promoUrl` | нет, только парой | Каждое вхождение кода в **`text`** (не в points/note) становится плашкой-ссылкой `.zn-promo`. `promoUrl`: `https://vk.ru/app54612839#promo=<КОД>`. Код обязан буквально стоять в `text`. |
| `event` | нет | Ключ из `EVENTS` -> баннер над записью (кликабелен, открывается крупно). Неизвестный ключ - баннера нет. |
| `when` | нет | Время события ISO **с поясом**: `"2026-11-15T18:00:00+03:00"`. Работает только вместе с `event`, у баннера которого есть точка `zn-ev-dot`. |

Других полей код не читает.

Показ: запись №1 (`FULL = 1`) - полностью (баннер, text, note, points, shots, ссылка); №2-3 (`SHOW = 3`) - одной строкой «дата - заголовок - стрелка в ВК» (text/points/shots/баннер скрыты); остальные - только после кнопки «Все новости» (она появляется, если записей больше 3). В развёрнутом виде все записи полные.

### Значения `event` (таблица `EVENTS` в news.js)

| `event` | Картинка | Метка, цвет `--ev` |
|---|---|---|
| `halloween` | `assets/event-halloween-*` + анимация тыквы и Излома | «Скоро» (без точки - `when` не работает) |
| `update` | `/assets/event-update-*` | «Слухи», бирюзовая, мигающая точка |
| `update-halloween` | `/assets/event-update-halloween-*` | «Слухи» |
| `release` | `/assets/event-update-*` (тот же кадр) | «Вышло», зелёная |
| `halloween-end` | `/assets/event-halloween-end-*` | «Завершён», оранжевая, точка не мигает (`.zn-ev-ended`) |
| `giveaway` | `/assets/event-giveaway-*` | «Розыгрыш», золотая |
| `raid` | `/assets/news/2026-11-08-raid-bosses.webp` (1774x887, кадр 2:1 без затемнения) | «15 ноября», оранжевая; с `when` - таймер |

`raid` жёстко привязан к картинке рейда 15 ноября 2026: для другого рейда с другой картинкой заведи новый ключ (см. ниже), не переиспользуй.

### Таймер `when` (`eventState`)

Метка баннера заменяется по времени (дни по МСК): «Через N дней» -> «Завтра в ЧЧ:ММ» -> «Сегодня в ЧЧ:ММ» -> «Идёт сейчас» (3 часа, `EVENT_HOURS`) -> «Завершён» + класс `zn-ev-ended` (точка гаснет; у `raid` кадр сереет, у остальных метка оранжевая). Считается один раз при загрузке страницы (без живого тиканья) и ещё раз при сборке для статичного HTML. Для многодневных ивентов `when` не годится (через 3 часа станет «Завершён») - ставь обычный `event` без `when`. Без `+03:00` время прочитается как местное у посетителя.

Реальный пример (анонс с таймером и заметкой):

```js
  {
    date: "2026-11-08",
    title: "Рейд на боссов от Наёмников, Долга и Свободы",
    text: "Совместный рейд пройдёт 15 ноября в 18:00 МСК. Присоединиться может любой сталкер Зоны.",
    note: { title: "Информация для новичков", text: "с 18:00 по боссам будет вноситься много урона. ..." },
    when: "2026-11-15T18:00:00+03:00",
    event: "raid"
  },
```

## Источник: пост ВК

Группа игры - `https://vk.ru/wall-239092289_NNN`, приложение игры - `https://vk.ru/app54612839`. WebFetch и curl текста поста НЕ получают (vk.ru -> m.vk.ru, «браузер устарел»/пустая SPA). Работает headless Chrome через `playwright-core` из репозитория (без входа в ВК). Сохрани скрипт ВНЕ репозитория, например `/tmp/vk-post.js`, и запусти из корня репозитория `node /tmp/vk-post.js https://vk.ru/wall-239092289_312`:

```js
const { openBrowser } = require(process.cwd() + "/build-chrome.js");
(async () => {
  const { browser, why } = await openBrowser();
  if (!browser) throw new Error(why);
  const p = await browser.newPage({ locale: "ru-RU" });
  await p.goto(process.argv[2], { waitUntil: "networkidle", timeout: 45000 }).catch(() => {});
  console.log(await p.evaluate(() => document.body.innerText));
  const links = await p.evaluate(() =>
    [...document.querySelectorAll("a[href]")].map(a => decodeURIComponent(a.href)).filter(h => /promo=|away\.php|app\d/.test(h))
  );
  console.log([...new Set(links)].join("\n")); // полные ссылки: в тексте промокод обрезан «promo=AG...»
  const imgs = await p.evaluate(() =>
    [...document.images].filter(i => i.naturalWidth >= 300 && /vkuserphoto|userapi/.test(i.src)).map(i => i.src)
  );
  for (const u of new Set(imgs)) {
    const as = (/[?&]as=([^&]+)/.exec(u) || [])[1]; // самый крупный размер из as=
    console.log(as ? u.replace(/([?&]cs=)[^&]+/, "$1" + as.split(",").pop().replace(/x\d+$/, "x0")) : u);
  }
  await browser.close();
})();
```

Текст поста - между «Пост на стене … Действия» и «Лайк». Дата в ВК относительная («4 д назад») - посчитай от сегодняшней даты по МСК, при сомнении спроси. `pp.vkuserphoto.ru/...500x500` - аватар группы, не картинка поста. Нет Chrome/сети или пост закрыт - попроси у пользователя текст поста и скриншоты. Слухи («Птичка-1», ответы администрации в чатах) обычно приходят только текстом/скриншотами от пользователя.

## Картинки

- Скриншот новости: `assets/news/<дата новости>-<латиница-через-дефис>.webp` (крупная, исходный размер, не шире ~1280) и `...-480.webp` (превью **480x300**, обрезка по центру под рамку 16:10 `.zn-shot`). Webp ~80 качества; у существующих крупные 200-1800 px, 5-380 КБ.
- Баннер события: `assets/event-<тип>-1200.webp` (**1200x375**) и `-600.webp` (600x187), `.zn-event` держит `aspect-ratio: 1200/375` с `object-fit: cover`. Откуда берутся сами арты баннеров, в репозитории не записано - новый арт попроси у пользователя (Sof) или используй существующий тип.
- Инструменты окружения: `ffmpeg` с `libwebp` - есть и проверен; `python3` без PIL; `cwebp` нет; Chrome + `playwright-core` есть (`build-chrome.js`, `CHROME_PATH`). Рецепт:

```sh
ffmpeg -v error -y -i in.png -vf "scale='min(1280,iw)':-1" -c:v libwebp -quality 82 -compression_level 6 assets/news/2026-11-09-name.webp
ffmpeg -v error -y -i in.png -vf "scale=480:300:force_original_aspect_ratio=increase,crop=480:300" -c:v libwebp -quality 80 -compression_level 6 assets/news/2026-11-09-name-480.webp
ffmpeg -v error -y -i art.png -vf "scale=1200:375:force_original_aspect_ratio=increase,crop=1200:375" -c:v libwebp -quality 82 assets/event-TYPE-1200.webp
ffmpeg -v error -y -i art.png -vf "scale=600:187:force_original_aspect_ratio=increase,crop=600:187" -c:v libwebp -quality 80 assets/event-TYPE-600.webp
```

Без ffmpeg - канвас в Chrome по образцу `build-guide-images.js` (`c.toDataURL("image/webp", 0.8)`). Размер проверить: `ffprobe -v error -show_entries stream=width,height -of csv=p=0 файл.webp`.

## Сценарии

**1. Новость по посту ВК («вышло обновление», «вот пост»).** Достань текст скриптом выше -> вставь объект в начало `ZONE_NEWS`: `date`, `title`, `text` (суть одной фразой), `points` (пункты поста, 3-6), `url` поста, `event: "release"` для вышедшего обновления (`update` - для анонса/слухов, `giveaway` - розыгрыш). Картинки поста, полезные игроку (награды, новые вещи), - в `shots`; обложку-баннер поста обычно не берут.

**2. Слух.** `title: "Слухи: ..."`, `event: "update"` (или тематический вроде `update-halloween`), `url` обычно нет. Формулировки с оговорками: «скорее всего», «по слухам», «могут поменяться». Источник «Птичка-1» упоминай, только если пользователь так сказал; шаблон: «Наш шпион под кодовым именем «Птичка-1» раскопал для вас ...». Скриншоты - в `shots`.

**3. Анонс события с таймером.** `date` - день анонса, `when` - начало с `+03:00`, `event` - тип с точкой в метке (`raid` или новый). Советы новичкам/условия - в `note`. После события ничего править не нужно: метка сама станет «Завершён».

**4. Событие завершилось / обновить старую запись.** Если игра выпустила пост об окончании - новая запись сверху (так сделано для Хэллоуина: `event: "halloween-end"`). Мелкие правки (перенос даты, уточнение) - в старой записи на месте, `date` и позицию не меняй. Старые записи не удаляй без просьбы.

**5. Новость с промокодом.** `promo: "КОД"`, `promoUrl: "https://vk.ru/app54612839#promo=КОД"` (полную ссылку бери из href - в тексте ВК она обрезана), и код обязательно в `text`, например «… и промокод ARENA2026».

**Новый тип баннера.** 1) Картинки `assets/event-<тип>-600/1200.webp`. 2) В `EVENTS` скопируй строку `giveaway`, поменяй класс `zn-ev-<тип>`, пути и текст метки; оставь `aria-hidden="true">` (по нему `banner()` делает баннер кнопкой), `<i class="zn-ev-dot"></i>` (по нему работает `when`) и пути с ведущим `/`. 3) В `home.css` рядом с `.zn-ev-giveaway`: `.zn-ev-<тип> { --ev: #цвет; }` и, если кадр тёмный, `filter` для `img`. Нестандартный кадр (как `raid` 2:1) - свой `aspect-ratio` и `src/srcset` из `assets/news/` по образцу `.zn-ev-raid`. Класс должен буквально встречаться в news.js, иначе очистка CSS в `build.js` его выкинет.

## Стиль текста

- Русский, «ёлочки», только дефис « - » (длинное тире из поста ВК заменяй), буква «ё». Без точки в конце `title`, `text`, `points` (так у большинства записей).
- `title` ~35-60 знаков: «Вышло обновление: картёжник и первое оружие на стенде», «Слухи: обменник, группировки и «Двадцать одно»», «Хэллоуинский ивент завершён», «Скоро Хэллоуин в Зоне».
- `text` 1 фраза, ~80-200 знаков: перечень главного через запятую. `points` - по одному факту, от третьего лица («разработчики», «администрация»), без «Сталкеры!», «Удачной охоты», смайлов. Цифры и время сохраняй точно: «500 000 HP», «в 05:00 и 18:00 по МСК».
- Не выдумывай факты сверх поста; непонятное из поста спроси.

## Подводные камни

- Сообщение коммита ни на что не влияет: в «Новости сайта» коммиты не попадают (они пишутся руками в `site-news.json`). Если меняется сам сайт (например, новый вид баннера) и Sof хочет это объявить - добавь запись по скиллу site-news.
- Не запускай для проверки `npm run build` без нужды: первым идёт `build-changelog.js`, он переписывает `changelog.js`. Для новостей хватает `node build.js` или `node dev.js`.
- `news.js` выполняется при сборке в заглушке DOM: синтаксическая ошибка валит `node build.js`; новый код отрисовки должен переживать отсутствие `querySelector`/`addEventListener` (как существующие проверки).
- Пути картинок в news.js - с ведущим `/assets/...`, иначе `build.js` не поставит `?v=` и после замены файла у посетителей останется старый кэш.
- Push в `main` сразу деплоится (GitHub Pages).

## Проверка

1. `npx prettier --check news.js home.css` и `npx eslint news.js`; затем `node build.js` (ловит синтаксис и пустой рендер).
2. `node dev.js` -> http://localhost:3000/ : новая запись первой, NEW у свежих, баннер и метка верные, промокод - плашка-ссылка, «Читать в ВК» ведёт на пост; вторая-третья записи - одной строкой; «Все новости» раскрывает остальное; клик по баннеру/скриншоту открывает окно просмотра, стрелки листают. Проверь ширину ~390 px.
3. Таймер: временно подставь `when` на прошлое/завтра, посмотри метки, верни значение.
4. Общая проверка, коммит и PR - скилл verify-and-ship.
