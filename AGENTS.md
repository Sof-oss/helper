# Инструкции для ИИ-агентов

Сайт «Сердце Зоны» (https://heart-of-the-zone.ru/) - статический сайт-помощник для игры. Описание для игроков -
[README.md](README.md), техническое - [DEVELOPMENT.md](DEVELOPMENT.md).

Перед задачей открой подходящий скилл из `.claude/skills/<имя>/SKILL.md` и работай по нему:

| Скилл | Когда брать |
| --- | --- |
| `zone-news` | «Новости Зоны» на главной: новость игры по посту ВК, слухи, анонс рейда/ивента, промокод, баннер события |
| `site-news` | «Новости сайта»: что изменилось на самом сайте, теги коммитов `new:`/`up:`/`fix:` |
| `guides` | Гайды: написать, принять гайд из формы (PR), обновить, картинки гайда |
| `game-info` | «Информация»: уровни, задания, боссы, ивентовые боссы |
| `calculator` | Калькулятор урона: снаряжение, таланты, арена, формулы, ссылки на билд |
| `factions` | Группировки, штабы, набор и контакты, темы оформления в цветах группировок |
| `top100` | Топ-100, ежедневная выгрузка, «Личное дело», сравнение, нашивки игроков |
| `seasonal-events` | Праздничное оформление (Хэллоуин, будущие праздники) |
| `site-dev` | Устройство сборки, новая страница, меню, CSS/CSP/PWA, превью и иконки, документация |
| `verify-and-ship` | В конце любой задачи: тесты, линт, формат, сборка, скриншоты, коммит, PR, проверка деплоя |

Главное:

- Push в `main` сразу выкладывает сайт. По умолчанию - ветка и PR, если владелец (Sof) не сказал иначе.
- Перед публикацией: `npm test && npm run lint && npm run format:check` и `node build.js` (подробно - `verify-and-ship`).
- Не запускай `npm run build` ради проверки: он переписывает `site-news.json` и `changelog.js`.
- Тексты на сайте - по-русски, кавычки «ёлочки», только дефис «-».
- Новая служебная папка или файл в корне попадёт на сайт, если не добавить имя в `SKIP` в `build.js`.
